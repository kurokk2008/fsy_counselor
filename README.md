# FSY カウンセラープログラムガイド

GitHub Pages でそのまま公開できる静的サイト版です。

## 公開手順
1. GitHub で新しいリポジトリを作成
2. このフォルダ内の `index.html` をアップロード
3. GitHub の `Settings` → `Pages`
4. `Build and deployment` で `Source` を `Deploy from a branch` に設定
5. `Branch` を `main` / `/ (root)` に設定して保存
6. 数分後に公開URLが発行されます

## 含まれるファイル
- `index.html` : 本体
- `.nojekyll` : GitHub Pages 用
